# Altair Kids

Сайт детского бутика **Altair Kids**, разработанный на **Next.js**.
Сайт представляет каталог товаров, информацию о магазине и способы связи с ним через WhatsApp.

## 🌐 О проекте

Altair Kids — это современный сайт-каталог детской одежды.

На сайте пользователь может:

* просматривать каталог товаров;
* открывать карточку товара;
* просматривать информацию о товаре;
* узнавать информацию о магазине;
* находить контактную информацию;
* связаться с магазином через WhatsApp.

Сайт не является полноценным интернет-магазином — оформление заказа происходит через WhatsApp.

## ✨ Основные возможности

### Каталог товаров

Товары хранятся в базе данных **Supabase** и динамически загружаются на сайт.

Для каждого товара могут храниться:

* название;
* описание;
* цена;
* изображение;
* категория/теги;
* дополнительная информация.

Добавление и изменение товаров производится непосредственно через Supabase, поэтому для обновления каталога не требуется изменять код сайта.

### Связь через WhatsApp

Вместо сложной системы корзины и онлайн-оплаты пользователь может связаться с магазином через WhatsApp.

Это позволяет быстро уточнить:

* наличие товара;
* размер;
* цвет;
* детали заказа;
* условия покупки.

## 📄 Страницы сайта

Основные разделы:

* `/` — главная страница;
* `/catalog` — каталог товаров;
* `/new` — новинки;
* `/boys` — одежда для мальчиков;
* `/girls` — одежда для девочек;
* `/about` — информация о магазине;
* `/contacts` — контактная информация;
* `/detail/[slug]` — полная информация о товаре.


Также могут использоваться динамические страницы отдельных товаров.

## 🚀 Запуск проекта

Установите зависимости:

```bash
npm install
```

Запустите development-сервер:

```bash
npm run dev
```

После запуска сайт будет доступен по адресу:

```text
http://localhost:3000
```

## 📦 Сборка проекта

Для production-сборки:

```bash
npm run build
```

Запуск production-версии:

```bash
npm start
```

## 🔄 Как работает каталог

Общая схема работы:

```text
Supabase
    ↓
PostgreSQL
    ↓
Next.js
    ↓
Получение товаров
    ↓
Каталог
    ↓
Карточка товара
    ↓
WhatsApp
    ↓
Связь с магазином
```

Товары добавляются в Supabase → Next.js получает данные из базы → данные отображаются пользователю в каталоге.

## 🎯 Особенности проекта

Главная идея проекта — сделать простой и удобный **сайт-каталог**, без необходимости реализовывать полноценную систему интернет-магазина.

Вместо:

```text
Товар → Корзина → Оформление → Оплата
```

используется более простой сценарий:

```text
Товар → WhatsApp → Общение с магазином → Покупка
```

Это уменьшает количество технических компонентов и позволяет владельцу магазина самостоятельно управлять каталогом через Supabase.
